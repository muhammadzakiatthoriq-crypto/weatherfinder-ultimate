# WeatherFinder Ultimate

## Deskripsi

Aplikasi cuaca berbasis React Native menggunakan Open-Meteo API.

## Fitur Level 1

* Search Kota
* Debounce 500ms
* useEffect
* AbortController
* Loading State
* Error State
* Success State

## Fitur Level 2

* Forecast 7 Hari
* Riwayat Pencarian
* Background Dinamis
* Arah Mata Angin
* Refresh Button
* Mode Siang/Malam

## Fitur Level 3

* Multi Kota
* Kota Favorit
* Pull To Refresh
* Animasi Fade In

## Cara Menjalankan

```bash
npm install
npx expo start
```

## Tech Stack

* React Native
* Expo
* Open-Meteo API
